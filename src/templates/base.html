How to use LEI lookup

LEI lookup finds a company's Legal Entity Identifier (LEI) in the GLEIF database. If a search by ISIN isn't found directly in GLEIF, the tool falls back to OpenFIGI (a free Bloomberg service) to look up the issuer by name.

Single lookup

  1. Enter an entity name or an ISIN (at least one; giving both, or adding an address, improves the result).
  2. Optionally add country, city, street, or postal code to narrow the result.
  3. Click Search.

Bulk lookup

  1. Prepare an .xlsx or .csv file, one entity per row, each with a name or an ISIN. Column order (header names don't matter): Name, ISIN, Country, City, Street, Postal code.
  2. Drag the file onto the upload area, or click to select it.
  3. Click Search.

Choosing the right match

Every searched entity lands in one group: Matched (a confident LEI), Need validation, or Unmatched.

  1. For each entity that needs validation, the tool lists the closest candidates it found. Click Correct match on the right one, or None of these if none fit.
  2. Your choices are saved and flow into the CSV and Excel downloads.
